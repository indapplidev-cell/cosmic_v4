# О нас

Cosmic — мобильное приложение-игра, где важны реакция, внимание и стабильный прогресс. Мы делаем продукт, который одинаково хорошо работает на разных устройствах, не требует лишних разрешений и остаётся удобным даже при нестабильном интернете.

## Наша цель

- дать честный, понятный игровой процесс без скрытых механик;
- сохранить результаты и профиль пользователя так, чтобы данные были доступны на разных устройствах;
- обеспечить предсказуемую работу приложения: быстрый запуск, корректные обновления, прозрачные правила.

## Как работает приложение

- учётная запись используется для входа и синхронизации данных;
- профиль и игровые показатели (например, рекорд, рейтинг, баланс) хранятся и обновляются через серверную часть приложения;
- часть информации может временно храниться на устройстве (кэш) для ускорения работы, но при наличии сети данные сверяются и актуализируются.

## Безопасность и ответственность

Мы применяем современные подходы к защите данных (включая хранение паролей в виде хеша на сервере). При этом безопасность также зависит от пользователя: не передавайте доступ третьим лицам и используйте надёжный пароль.

Приложение может содержать ссылки на сторонние сервисы/площадки партнёров. Пользователь самостоятельно принимает решения о действиях на таких ресурсах; Разработчик не отвечает за содержание, условия и доступность сторонних сервисов.
